# 너마날아

**너(의) 마(음의) 날(씨를) 아(려줘)** — 등교한 학생이 날씨 그림 하나를 눌러 오늘의 마음을 알리고, 교사는 그 기록으로 먼저 살펴볼 학생을 찾아 말을 걸 수 있도록 돕는 학급용 웹 앱입니다.

Edu-Inno 교육혁신 공모전 · 분야 2 (AI 활용 교육용 앱)

- 실행 주소: https://dnue2024.github.io/neomanara/
- 소스코드: https://github.com/dnue2024/neomanara

## 주요 기능

- **5초 마음 날씨 입력**: 번호 → 비밀번호 4자리 → 날씨 선택. 교실 앞문의 태블릿에서 입력합니다.
- **하고 싶은 말(선택)**: 기분 태그, 이유 글, 선생님께 하고 싶은 말, 단둘이 이야기 요청.
- **먼저 살펴볼 학생 알림**: 위기·주의·관찰 3단계. 학생 한 명이 카드 한 장으로 모입니다.
- **AI 글 분석**: 글을 읽고 감정·한 줄 요약·위험도를 만들고, 날씨와 글이 어긋나는지 찾습니다.
- **AI 말 걸기 문구**: 알림이 뜬 학생에게 건넬 열린 질문과 조심할 점을 제안합니다.
- **조치 기록**: 교사가 지도한 내용을 계속 보관하고 CSV로 내려받을 수 있습니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 화면(학생용 태블릿 화면 + 교사용 화면). 별도 설치 없이 브라우저에서 실행됩니다. |
| `Code.gs` | 서버(Google Apps Script). 구글 스프레드시트에 기록을 저장하고 비밀번호 확인, Gemini AI 호출을 맡습니다. AI 프롬프트(`SYS_ANALYZE`, `SYS_DRAFT`)도 이 파일에 있습니다. |
| `설치안내.md` | 구글 스프레드시트·Apps Script 연결 방법. |

## 실행해 보기

1. 위 실행 주소를 엽니다.
2. 서버를 연결하지 않으면 **데모 모드**로 열립니다. 이 기기에만 저장되는 가상 데이터로 화면을 둘러볼 수 있고, AI 대신 간단한 규칙이 동작합니다.
3. 실제로 쓰려면 `설치안내.md`에 따라 구글 스프레드시트에 `Code.gs`를 연결하고, 화면의 '연결 설정'에 웹 앱 주소를 입력합니다.

## AI 사용 방식

- Google Gemini API를 서버(`Code.gs`)에서만 호출하며, API 키는 서버의 스크립트 속성에만 저장합니다. 코드에는 포함되어 있지 않습니다.
- AI에는 학생 이름 없이 **번호만** 전달합니다.
- AI는 진단하지 않는 보조 도구입니다. 위기 단어는 AI와 별개의 규칙으로 감지하며, 최종 위험도는 규칙과 AI 중 높은 값을 씁니다.

## 개인정보

- 학생 이름은 교사 컴퓨터의 브라우저에만 저장됩니다.
- 학생 비밀번호는 암호화된 값으로만 저장됩니다.
- 실제 학급에 적용할 때는 학교 지침과 학부모 안내가 필요하며, 학기 말 기록 삭제 절차를 두세요.
